# Fight Gym CRM

Proyecto de prácticas: CRM para un gimnasio de deportes de contacto.

## Funcionalidades solicitadas
- Alumnos
- Profesores
- Actividades
- Pagos
- Asistencias
- Facturación
- Estadísticas
- Login
- Dashboard

## Tecnologías solicitadas
- Python 3
- PySide6 / PyQt6
- SQLite
- Pandas
- Matplotlib
- Git
- GitHub

## Arquitectura
- `app/ui` → interfaz gráfica
- `app/data` → base de datos
- `app/services` → lógica de negocio
- `app/reports` → informes
- `app/config` → configuración

## Ejecución
Coloca el proyecto en una ruta corta, por ejemplo `C:\CRM`, y ejecuta `INICIAR.bat`.

Usuario: `admin`
Contraseña: `admin123`

## Git / GitHub
```bash
git init
git add .
git commit -m "CRM gimnasio"
```

Después crea el repositorio en GitHub y conecta el remoto que GitHub te indique.
